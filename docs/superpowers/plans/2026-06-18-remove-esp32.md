# Remove the ESP32 Device Subsystem Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the obsolete ESP32 / `Device` subsystem end-to-end (REST ingest endpoints, model, claim flow, device pages, admin device count), leaving Shelly Cloud as the sole sensor source.

**Architecture:** Deletion-only refactor. The shared sensor pipeline (`sensorStore`, `hourAccum`, `upsertCurrentHour`/`saveHourlyData`, `SENSOR_DATA_CHANNEL`, `sensorData`/`hourlySensorData` GraphQL) is **kept** — the Shelly poller feeds it. `handleSensorData` is simplified to the userId-provided path (what the poller uses). The dashboard is untouched.

**Tech Stack:** TypeScript, Express, Mongoose, Apollo Server; Angular 21 standalone, Transloco, Tailwind.

**Spec:** `docs/superpowers/specs/2026-06-18-remove-esp32-design.md`

**Resolved pre-checks (confirmed against current code):**
- `saveHourlyData`, `superuserId`, `setSuperuserId` are **kept** — `saveHourlyData` is called by the hourly aggregation cron (`startHourlyAggregation`, resolvers.ts ~line 246) and `superuserId` backs seed/migration + the hourly fallback. Only the `/api/save-hourly` *route* is removed.
- `deviceClaimedChannel` (pubsub) is used only by the claim flow → removed once that flow is gone.
- `handleSensorData` is exported and called by the Shelly poller with `{ deviceId, temperature, humidity, userId }`.

**Tests:** Backend has no test runner — verify with `npx tsc --noEmit` (run in `backend/`) + a final grep gate. Frontend: `npx tsc -p tsconfig.app.json --noEmit` (strict templates) + JSON validity + grep. **Do not** run `npm run build` (prebuild overwrites `environment.prod.ts`).

**Commits:** to `master` (project convention). End each commit body with `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`.

```ts
// ── Device claim window (in-memory) ─────────────────────────────────────────
// userId → expiresAt (ms epoch). Cleared on bind or expiry.
const CLAIM_WINDOW_MS = 10 * 60 * 1000;
const pendingClaims = new Map<string, number>();

function openClaim(userId: string): number {
    const expiresAt = Date.now() + CLAIM_WINDOW_MS;
    pendingClaims.set(userId, expiresAt);
    return expiresAt;
}

function cancelClaim(userId: string): boolean {
    return pendingClaims.delete(userId);
}

function purgeExpiredClaims() {
    const now = Date.now();
    for (const [uid, exp] of pendingClaims) {
        if (exp <= now) pendingClaims.delete(uid);
    }
}

function activeClaimants(): string[] {
    purgeExpiredClaims();
    return [...pendingClaims.keys()];
}
```
